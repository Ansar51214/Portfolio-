## Local development

```bash
# Clone
git clone https://github.com/Ansar51214/Portfolio-.git
cd Portfolio-

# Install (npm or bun)
npm install
# or: bun install

# Env
cp .env.example .env
# Set VITE_WEB3FORMS_ACCESS_KEY=your_key_from_web3forms.com

# Dev server
npm run dev
```

### Scripts

| Command | Description |
|---------|-------------|

## Environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `VITE_WEB3FORMS_ACCESS_KEY` | For contact form | Access key from [web3forms.com](https://web3forms.com) |

Set the same variable in **Vercel → Project → Settings → Environment Variables** for Production / Preview.
